# brainrotter (formerly Reelapse)

Short-form platforms are dominated by faceless, algorithm optimized content but making it at scale is slow, manual, and exhausting. Our tool simplifies this for content creators.

What it does
Brainrotter turns any topic into a complete, viral-style faceless short with script, pacing, and captions generated automatically. This helps short form content creators in relating to their newer generation audiences.

For setup, run `setup.ps1` for Windows, or `setup.sh` for MacOS/Linux
For deployment, Run `run.ps1` for Windows or `run.sh` for MacOS/Linux
